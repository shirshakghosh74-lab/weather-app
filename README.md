# 🌤️ Weather App

A clean, responsive weather application built with vanilla HTML, CSS, and JavaScript, using the OpenWeatherMap API for real-time weather data.

**🔗 Live Demo:** [https://shirshakghosh74-lab.github.io/weather-app/](https://shirshakghosh74-lab.github.io/weather-app/)

## ✨ Features

- 🔍 **City Search** — search current weather for any city worldwide
- 🌍 **Autocomplete Suggestions** — real-time city name suggestions as you type
- 📍 **Auto-Location Detection** — automatically loads weather for your current location on first visit
- 🕒 **Remembers Last Search** — reopens with your last searched city
- 🌦️ **Dynamic Weather Icons** — matches current weather conditions
- 🎨 **Dynamic Background** — background gradient changes based on weather (sunny, rainy, cloudy, snowy, etc.)
- 📅 **5-Day Forecast** — daily forecast with icons and temperatures
- 🌡️ **°C / °F Toggle** — switch between Celsius and Fahrenheit instantly
- 🤔 **"Feels Like" Temperature** — alongside actual temperature
- 🌅 **Sunrise & Sunset Times**
- 🕓 **Recent Searches** — quick-access chips for your last 5 searched cities
- 🌙 **Dark Mode Toggle** — with saved preference across visits
- ⏳ **Loading Spinner** — smooth loading state during API calls
- 💎 **Glassmorphism UI** — modern frosted-glass card design with smooth animations

## 🛠️ Built With

- HTML5
- CSS3 (Glassmorphism, animations, responsive design)
- Vanilla JavaScript (Fetch API, LocalStorage, Geolocation API)
- [OpenWeatherMap API](https://openweathermap.org/api) (Current Weather, 5-Day Forecast, Geocoding)

## 🚀 Running Locally

1. Clone this repository
2. Open `index.html` with a live server (e.g., VS Code's Live Server extension)
3. Replace the `apiKey` variable in `script.js` with your own free OpenWeatherMap API key
